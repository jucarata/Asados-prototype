# ASADOS 24/7 — Menú digital (mock)

Mock de venta: menú digital mobile-first con carrito y preview de orden a WhatsApp.

## Desarrollo

```bash
npm install
npm run dev
```

Abre `http://localhost:4321` (mejor en viewport ~390px).

## Build

```bash
npm run build
npm run preview
```

## Rutas

- `/` — Home con mascota
- `/menu` — Menú + carrito
- `/orden` — Preview del mensaje WhatsApp (demo, no envía)
